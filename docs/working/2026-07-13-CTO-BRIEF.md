## Decisions already made — please honor these (summarized; detail in linked docs)
| Area | Decision |
|---|---|
| **Architecture** | Server-authoritative. The duel core runs **server-side only**, never in the browser; thin web clients. |
| **Engine** | Reuse `edo9300/ygopro-core` (ocgcore) + ProjectIgnis CardScripts + `cards.cdb`. **AGPL-3.0 accepted**; app stays **private**. |
| **Engine build** | Custom WASM from edo9300 **@ `8e5f4e4`** (emcc 6.0.2), reproducible build script. **Edison duelFlags = `0x7f80d072c`** (`MODE_GOAT | TCG_FAST_EFFECT_IGNITION`) — but **express it as an explicit, per-flag-commented bitmask, not a `MODE_GOAT` reference** (GOAT≠Edison; the value coincides because the mechanics are shared pre-MR2). |
| **Ruleset** | Edison = Master Rule 1 era + validated era flags (first-turn draw, 1 field spell, ignition priority incl. GY, 0-ATK, 6-step damage step, SEGOC). Xyz/Pendulum/Link forbidden. |
| **Card text (display)** | **Verbatim March-2010 text** for the 35 functional cards; images stay modern. |
| **Pre-errata (gameplay)** | Curate a pre-errata **script** set for the functional cards; keep a documented "left on modern text" gap list. |
| **Card pool** | Locked to the edisonformat.net convention (through DPKB 2010-04-20; exclude TSHD + the 27 DT01 cards). ~3,681 cards. |
| **Hosting** | Vercel frontend + Fly backend (split); SQLite + self-hosted images on a Fly volume. WebSockets land on the same Fly backend. |
| **Duel timer** | Configurable **per-move auto-forfeit** timer chosen at duel creation; supports synchronous and multi-day asynchronous play. Server-authoritative time. |
| **V1 scope** | Rules-**enforcing** duel that surfaces legal actions + priority windows. **No** "why is this illegal?" explainer (that's V2). |

## Open decisions / gaps for you to account for moving forward
1. **#10 — LP cost that reduces LP to exactly 0.** Genuine engine gap: `check_lp_cost`/`PayLPCost` use `<=` (allows pay-to-0, modern) with **no era flag**; Edison forbids it. **Decision needed: patch the fork (`<`, ideally behind a flag) or accept + document the exception.** Product lean: patch (small change, and accuracy is the promise) — but it's your call on fork-maintenance cost. Low frequency.
2. **Script curation scope** — how many of the 17 "diff-vs-modern" cards actually need authored scripts vs are already behavior-correct in the modern script (display-only difference). Diff before authoring.
3. **The empirical rule tests** (#5/#9/#11 confirm; #7/#8/#4 test) — fold into the dueling test suite; `verify` gates them.
4. **Documented residual-gap list** — anything knowingly left on modern behavior gets recorded (accuracy-honest, not hidden).

## Definition of done (accuracy bar)
A duel of two legal Edison decks reproduces March-2010 behavior on the format-defining interactions (ignition priority, the functional-errata cards, damage step, field spell), with every knowing deviation documented. Repo rules apply: tests merge with each feature; green `npm run verify` is sign-off; respect the dependency graph in `AGENTS.md`.
