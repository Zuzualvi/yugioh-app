# Edison "Functional Errata" Cards — Edison-correct vs Modern behavior, community mitigation & script availability

**Purpose:** Authoritative, complete list of the cards whose Yu-Gi-Oh! text/behavior *changed after March–April 2010* ("functional errata"), so Edison Format uses their **pre-errata (2010) versions**. Feeds the pre-errata curation workstream (**Spike B**). Accuracy is the founder's #1 requirement, so every row is sourced; inferences are labeled.

**Task scope recap:** We reuse the ocgcore/EDOPro engine + ProjectIgnis Lua CardScripts + card DB. Engine RULES can be set to Edison via duel flags (see `engine-edison-rules.md`). The residual gap is that shipped CardScripts encode **modern card errata**, which is wrong for these cards. This file enumerates them.

## How the community mitigation actually works (verified mechanism)

EDOPro loads the **modern** script for a real passcode by default. To force pre-errata behavior, the community banlist does one of two things:

1. **Substitute passcode (true fix).** ProjectIgnis ships a *separate* pre-errata "card" with a distinct passcode (usually `511002xxx`/`511003xxx`, named "… (Pre-Errata)") whose `.lua` in `CardScripts/pre-errata/` is the 2010 behavior, and whose DB `alias` points back to the real card (so deck-building/banlist still counts it as the real card). The `Edison.lflist.conf` **forbids the modern passcode** (`#Modern Erratums`, `-1`) **and whitelists the pre-errata passcode** at its Edison limit. This genuinely changes gameplay.
2. **No substitute (accepts modern text).** For some cards the banlist lists the modern passcode `-1` in `#Modern Erratums` but then **re-whitelists the same modern passcode later** in `#unlimited/#semi-limited`. Because the parser is **last-wins** (`deck_manager.cpp:79`), the card ends up **legal at its modern-errata script** — i.e., the community *tolerates* the modern text for these.

The `#Anime Alias`/`#Goat Alias` entries are almost all `-1` (they *forbid* anime/alt-art/GOAT-passcode versions from sneaking in); they are generally **not** the errata substitutes. The true errata substitutes are the six `511002xxx` "(Pre-Errata)" entries whitelisted in `#limited Edison`.

**Consequence for our build:** because *we* control script loading per passcode, we are not limited to the banlist's six substitutes. Any Edison-accurate `.lua` that exists in `CardScripts/pre-errata/` (there are more than the banlist uses) can be wired straight to the real passcode. See "Script availability" column and the Spike-B recommendations.

## Recommendations for the pre-errata curation workstream (Spike B)

1. **Adopt the 6 community substitutes as-is** (Brionac, Sangan, Rescue Cat, Goyo, Brain Control, Future Fusion): wire real passcode → `pre-errata/c511002xxx.lua`. Zero authoring; verified OPT-free.
